## 视觉规范

借鉴 Tailwind/Geist（间距与灰阶）、Linear（细描边、无阴影）、Stripe Docs（两档排版）、
Notion（内容优先）、GitHub Primer（语义色）、Ant Design（14px 正文基准）。

| 维度 | 取值 |
| --- | --- |
| 字号 | **正文 16 / 辅助 13** / 区块标题 20 / 项目名 24（另：28 百分比、15 主按钮、10 头像字母） |
| 字重 | 400 / 600 / 700 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32（4px 基数，不出现中间值） |
| 圆角 | 8 卡片 / 6 控件 / 999 胶囊 |
| 中性色 | `#0f172a` 主文字 / `#475569` 次文字 / `#94a3b8` 辅助 / `#e2e8f0` 边框 / `#f1f5f9` 分隔 / `#f8fafc` 浅底 |
| 品牌色 | `#1a5bff` 主 / `#1550e6` hover / `#eef3ff` 浅底 |
| 状态色 | 三档都走品牌蓝：进行中＝浅蓝底 + 蓝字；已完成＝实心 `#1a5bff` + 白字；未开始＝浅灰 + 灰字（**完成态不用绿色**） |
| 功能色 | 危险 `#b42318` + `#fef3f2`（本页未使用） |
| 边框 | 只两种：卡片 1px `#e2e8f0`、区块分隔 1px `#f1f5f9` |
| 卡片 | 统一规格：圆角 8 + 1px 边框 + 内边距 16 + 无阴影，hover 只变边框色 |
| 主操作 | 全页只保留一个实心主按钮（继续科研任务），其余降级为描边按钮或文字链 |
| 数字 | 全部 `tabular-nums`，跨卡片基线对齐 |

v1 的实际状况（对比用）：12 档字号、30 个色值、约 30 种间距、6 种圆角。

## v3 相对 v2 的变化

1. **正文 14 → 16px、辅助 12 → 13px**（采纳文档站的正文规格），行高同步提到 24/20。
2. **左右对调**：核心内容移到左侧，研究过程导航移到右侧。
3. **右侧导航改为「ON THIS PAGE」式**：纯列表，当前项用 2px 品牌蓝竖线 + 蓝色序号 + 深色标题 + 状态，未选中项只有灰色标题。
4. **两个动作按钮改大圆角胶囊**（高度 44px），主按钮 15px/700、次按钮 16px/400 靠权重分主次。
5. **工作流卡片去掉按钮**，改为文字链 `了解工作流 →`。
6. **面板滚动条隐藏**：滚内容时右侧导航固定不动（两个独立滚动容器，都不显示滚动条）。
