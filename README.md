## 视觉规范（v2 的全部约束）

借鉴 Tailwind/Geist（间距与灰阶）、Linear（细描边、无阴影）、Stripe Docs（两档排版）、
Notion（内容优先）、GitHub Primer（语义色成对）、Ant Design（14px 正文基准）。

| 维度 | 取值 |
| --- | --- |
| 字号 | 24 项目名 / 20 区块标题 / 14 正文 / 12 辅助（另：28 百分比、15 主按钮、10 头像字母） |
| 字重 | 400 / 600 / 700 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32（4px 基数，不出现中间值） |
| 圆角 | 8 卡片 / 6 小元素 / 999 胶囊（另 4 给文件类型徽标） |
| 中性色 | `#0f172a` 主文字 / `#475569` 次文字 / `#94a3b8` 辅助 / `#e2e8f0` 边框 / `#f1f5f9` 分隔 / `#f8fafc` 浅底 |
| 品牌色 | `#1a5bff` 主 / `#1550e6` hover / `#eef3ff` 浅底 |
| 状态色 | 三档全部走品牌蓝：进行中＝浅蓝底 `#eef3ff` + 蓝字；已完成＝实心 `#1a5bff` + 白字；未开始＝浅灰 `#f8fafc` + 灰字（**完成态不用绿色**，绿色只留给"通过/达标"这类真实语义） |
| 功能色 | 危险 `#b42318` + `#fef3f2` |
| 边框 | 只两种：卡片 1px `#e2e8f0`、区块分隔 1px `#f1f5f9` |
| 卡片 | 统一规格：圆角 8 + 1px 边框 + 内边距 16 + 无阴影，hover 只变边框色 |
| 数字 | 全部 `tabular-nums`，跨卡片基线对齐 |

v1 的实际状况（对比用）：12 档字号、30 个色值、约 30 种间距、6 种圆角。

## 页面结构（已冻结）

```
固定头部：科研空间 ｜ 分享
├ 左栏：研究过程
│   · 进行中卡（阶段名 / 当前子任务 / 子任务进度 / 进度条）
│   · 后续阶段时序节点流（02→10）
└ 右栏
    ├ 项目条：项目名 / 研究目标 / 成员 / 继续科研任务 + 邀请加入空间 ｜ 更新时间 / 进度 / 4 个指标
    ├ 当前阶段：阶段名 + 状态 / 子任务卡（4 张，含执行人）/ 推荐工作流（2 张）
    └ 科研成果：tab 按阶段筛选 + 成果列表（含执行人、阶段、时间、来源）
```
